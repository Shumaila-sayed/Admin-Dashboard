# Admin Dashboard 🖥️

## Overview

This project is an **Admin Dashboard** built using **HTML** and **CSS**. It demonstrates the use of **CSS Grid** and **Flexbox** to create a clean, organized, and responsive layout. The dashboard includes a sidebar for navigation, a header with user info, and a main content area featuring project cards, announcements, and trending items.

## Key Features 🌟

- **Grid-based Layout**: Utilizes **CSS Grid** for an adaptable and structured design. 🗂️
- **Sidebar Navigation**: A clean sidebar for intuitive navigation across the dashboard. 🧭
- **Main Content**: Includes project cards, announcements, and trending sections. 📊
- **Material Design Icons**: Integrated icons from Material Design for a polished look. 🎨
- **Google Fonts**: Custom typography using Google Fonts for modern and readable text. 🅰️
- **Responsive Design**: The card system adjusts to different screen sizes. 📱💻
